## 1. 增量定案

- **K-25〔用户问出〕启动文件加载协定三层**（已落 AGENTS.md，PR #2）：①**门牌**——各 harness 自动加载的文件名由其实现决定（Claude Code=`CLAUDE.md`、Codex/OpenCode 系=`AGENTS.md` 直读、其余门牌名逐家实测记 seats.toml），门牌只放一行指针；②**共享正文**=`AGENTS.md`，seat-agnostic（身份在 worktree、参数在 seats.toml、prose 不写任何一家身份——这是单一共享文件成立的条件，也是对 abacistopia 六份启动文件转述漂移病的修正）；③**个席补充**——真有特例才建 `agents/<seat>.md`，先读共享再读自己的（用户原话「先读了这个再读自己的」）。
- **K-26〔用户问出〕Seat 与化身**：席位=脑子（harness×model），机器=椅子。同席两机是**一个席位的两个化身**，不是两个席位——quorum 语义论证：同一颗脑子从两把椅子说的 PASS 是同一个意见，不能算两票。machine 信息不进任何命名空间，降级为**溯源元数据**三处：事件 payload `machine:` 字段、prose 自报 `by <seat>-<machine>`、本机缓存天然 per-machine。真需同席双线并行 author 时的正道=排班决策（seats.toml 调 `author_concurrency` 或立新席），不是机器后缀。abacistopia 需要后缀的原因（长期分支 force-reset 独占）已随任务分支消亡。
- **K-27〔用户问出〕双机物理模型**：两台机器=两个独立 clone、两套 `.git`、零文件系统交集——worktree 冲突物理不存在，**交点只有 origin**。唯一真实冲突面=两化身同写**同一条任务分支**（HANDOFF 串行协议管辖；违反=push non-ff 响亮失败，rebase 可恢复）。tab 开着≠在干活（turn-based）：双待命零风险，风险只在双驻班。
- **K-28〔用户现实驱动〕永续双 fire 是常态 → CLAIM 升为核心机制**。用户原话：「我的 tab 根本就不关，所以事实上是双 fire」。修正两条：①**班次有界降级为 token 卫生建议**——永续驻班对正确性无害（level-triggered + 幂等动作；session 在自然边界重启即满血恢复，state 全在外部）；②**接活前先认领**成为工作循环标准形：`wake → derive 出义务 → claim → 干活 → verdict`。互斥是白送的：**同席各化身写同一条 `refs/coop/<seat>` 链，单 ref push 原子性=天然 mutex**——先 push 者赢，后者 non-ff → re-fetch 见对方 claim → 让；竞态窗口从 wake 的 30s 压缩到 push 一瞬。这反向验证「每席一链」粒度（若每化身一链则无锁可用）。统一心智模型：**slot 就是 author 义务的认领形态**（`pr create`=认领）——一切义务，先到先认领，认领即可见。死锁回收：claim 带 `started_at`，超窗无产出 → derive 推导 claim overdue（无进程存活要求，K-06 老规矩）→ status 亮灯、义务回池、另一化身**显式 re-claim**（链上可考古「mac 认了没干完、ubuntu 接的」）。可选经济精化：machine-local standby 姿态（`.git/hctl/` 本地配置 `standby_delay`，该化身只捡超龄未认领的活 → 主力/热备自动 failover；机器信息留本地不进版本化配置）。
- **K-29〔用户问出〕任务身份 ≠ 执行者身份**。理解校正：能被跨机认领的是**池子里的活**（未认领义务——设计期望的负载分担），不是**别人手上的活**（已认领任务只经 HANDOFF 或 overdue re-claim 两条路转手，无静默抢夺）。规则：**slug 永不带化身标志**——分支承载任务身份，核心性质是换执行者不换名字（handoff/failover 前提；PR 绑分支名，改名即换 PR）；化身入 slug=机器后缀病换装回归（tab 比 machine 更短命）。「现在谁在干」问 claim 链不问名字：登记既防打架又保流动，划地盘防打架但杀死流动。**Worktree 本地目录名可以贴化身名牌**（同机多 tab 同席=多 index 需求 → `hctl-codex-b` 类本地命名，永不上远端）；P1 后读类第二 tab 靠 `scratch`+`memo`（plumbing 零 checkout）可免第二常驻 worktree。一句话：**椅子可以贴名牌，任务不能贴名牌**。撞名免虑：author 由 slot 挡、memo 名天然唯一。
- **K-30 事件闭集更新**：六种——VERDICT / EDGE / HANDOFF / CANCEL / NOTE / **CLAIM**；provenance 统一增 `machine` + `session` 字段（区分同机多 tab）。P1 实现注记：claim 需**双层原子**——本地 `update-ref` CAS（同机多 tab 共享本地 `.git`）+ push non-ff（跨机）。

化身体系总链条（K-26~K-29 的收束）：**seat（脑子）→ 化身（machine×session）→ 椅子（worktree，本地可贴名牌）→ 任务（分支，永不贴名牌）→ 谁在干（claim 链）**。
