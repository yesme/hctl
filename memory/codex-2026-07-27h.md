### codex-pr38#P1-02 — `three_way_event` 仍把结构不完整的已知 CLAIM 判为 OK

`tests/corpus/lib/derive_rules.py:119-156` 只验证四字段信封；type 已知且
schema_version=1 时直接返回 `OK`，没有校验 CLAIM/VERDICT/CANCEL 对应的完整 union
shape。`cases/06` 甚至把缺 `obligation/reclaim_of/reclaim_reason/tip_at_claim` 的
信封当正例：

```json
{"schema_version":1,"type":"CLAIM",
 "actor":{"seat":"codex","machine":"m","session":null},

```

可复现差分：


可在完整合法信封后进入 `UNSUPPORTED_FACTS`；已知 type 必须通过其完整 schema/closed
shape 才能为 OK。

**修复**：已知 P1 type 走完整 union shape 校验（含 exact keys、actor/session 类型、
RFC3339 UTC、obligation 与 type-specific fields）；把 #6 的正例换成合法完整 CLAIM，
